# Bundled MS17 trial period table

Pdist_small.dat was supplied by Tian Qiu for distribution with RVBinary.
SHA256: 490592bec1d0a2c9708053102c38f0d105bb7c8230c23566d41e3a0faca73c50.
140400 rows, five columns; mass, log10(P/day), two component densities,
and total density (last column used). Complete grid: mass0.80–7.98,
logP0.20–7.98, spacing0.02. Trial data, NOT general MS17 coverage.
The implementation permits only0.8<=M1<1.2 solar masses and periods
inside both the table and logP[0.2,7.98]. No extrapolation. Built-in table
checksum is verified at load. See docs/models/README.md.
